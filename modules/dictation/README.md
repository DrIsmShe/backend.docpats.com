# Голосовая надиктовка истории болезни

Врач наговаривает приём, модуль распознаёт речь, раскладывает её по разделам
карты и отдаёт **черновик**. Запись в карту создаёт врач — сам, из формы.

Смонтирован в `index.js` как `/api/v1/dictation`, **после** session-middleware:
весь модуль опирается на `req.session.userId`.

## Что тут главное

**В карту не попадает ничего, чего не было в надиктовке.** Модель раскладывает
сказанное по полям и не имеет права дописывать. Пустой раздел остаётся пустым —
никаких «без особенностей» и «в норме», которых врач не говорил. Это проверяется
тестом `НЕ выдумывает содержимое: пустые поля остаются пустыми`, и это условие,
при котором функция вообще имеет право существовать в медицинской карте.

Второе: модуль не подписывает записи. `attachJob` создаёт историю болезни в
статусе `draft`. Подпись — отдельное действие врача обычным путём модуля.

## Устройство

```
providers/   сменные шаги: распознавание (stt) и сборка структуры (structure)
             плюс audio.store — доступ к файлу в хранилище
sinks/       куда приземляется черновик; сейчас только myClinic
worker/      циклы обработки (runner.js) и standalone-процесс
```

Про модуль-получатель знает ровно один файл — `sinks/myClinic.sink.js`. Когда
дойдёт очередь до `clinic`, добавится второй приёмник, движок останется
прежним. Тот же приём, что в `radiology/reading-systems` и `diagnostics/core`.

## Жизненный цикл задания

```
uploaded → transcribing → transcribed → structuring → drafted → attached
                    ↓ сбой                    ↓ сбой        ↓ отказ врача
                 (откат назад, до 3 попыток → failed)    discarded
```

Захват стадии атомарный (`findOneAndUpdate` в `processNext`), поэтому
потребителей может быть сколько угодно: одну стадию дважды не выполнят.
Задание, брошенное упавшим воркером в промежуточном статусе, возвращает в
очередь `reclaimStale` — без него оно висело бы вечно, а врач ждал бы черновик,
которого никто не делает.

## Голос пациента и врача

Аудио удаляется **после** прикрепления к карте, а не после распознавания:
пока врач правит черновик, у него должна быть возможность переслушать. При
отказе — стирается сразу. Брошенные задания подчищает ретеншн через
`EXPIRE_AFTER_DAYS` (7 дней).

Расшифровка и черновик лежат в базе зашифрованными (`encryptPHI` как
mongoose set/get) — это PHI ровно в той же мере, что и сама карта.

## Переменные окружения

Обязательные — без них `GET /status` вернёт `ready:false`, и панель записи в
интерфейсе просто не покажется:

| Переменная | Зачем |
| --- | --- |
| `OPENAI_API_KEY` | распознавание речи (Whisper) |
| `ANTHROPIC_API_KEY` | сборка структуры |

Необязательные:

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `DICTATION_INLINE_WORKER` | `true` | обработка внутри API-процесса |
| `DICTATION_STT_MODEL` | `whisper-1` | модель распознавания |
| `DICTATION_MODEL` | `claude-opus-5` | модель разбора |
| `DICTATION_EFFORT` | `low` | задача разметочная, не рассуждательная |
| `DICTATION_POLL_MS` | `5000` | опрос очереди |
| `DICTATION_RECLAIM_MS` | `300000` | как часто искать зависшие |
| `DICTATION_STALE_MS` | `600000` | с какого простоя задание считается зависшим |
| `DICTATION_RETENTION_MS` | `3600000` | как часто убирать аудио |
| `DICTATION_FETCH_TIMEOUT_MS` | `30000` | таймаут чтения аудио из хранилища |

## Деплой

Отдельный процесс поднимать **не нужно**: циклы стартуют внутри API-процесса
(`startDictationWorker()` в `index.js`). Достаточно обычного рестарта — но с
`--update-env`, потому что добавляются ключи:

```bash
pm2 restart all --update-env
```

Когда надиктовок станет много и распознавание начнёт мешать API:

```bash
# в .env API-процесса
DICTATION_INLINE_WORKER=false
# отдельным процессом
pm2 start npm --name dictation -- run worker:dictation
```

Оба режима одновременно безопасны — захват стадии атомарный.

## Тесты

```bash
npx vitest run __tests__/dictation
```

Проверяются границы, а не качество распознавания: конвейер, атомарность
захвата, возврат зависших, что попадает в карту, правка врачом, владение,
ретеншн и реестр приёмников. Сетевые вызовы замоканы — настоящие стоили бы
денег и зависели бы от сети.
